# Qual é o meu rumo?

Teste gratuito de orientação profissional: interesses (modelo RIASEC), escolhas, realidade e reflexão, com caminhos sugeridos, plano de 30 dias e placar de decisão.

Site: https://pedromanoel3000-bit.github.io/Qual-meu-rumo-/

As respostas ficam salvas só no aparelho de quem faz o teste (localStorage). Nada é enviado para servidor.

Não é um teste psicológico nem diagnóstico. Veja [Sobre o teste](sobre.html), [Privacidade](privacidade.html) e [Termos de uso](termos.html).
